# 《来自星星的礼物》H3 Max详细制作方案

2026-11-02｜30秒｜横屏16:9｜面向约9岁观众

本文件是制作计划，尚未提交视频生成任务。四张新增视觉参考已生成；木星使用“定妆照/jupyter”的三张图，蓝色矮行星使用“定妆照/planet”的无眼、闭眼、半睁眼与睁眼图。原故事文件名保留便于已有链接继续使用，正文片名已统一修改。

## 一、已经确定的故事与表现

五人小组借助木星引力加速抵达柯伊伯带，接连观察甜甜圈小行星、喷气冰石和双胞胎冰球。自动检测系统在蓝色矮行星旁发现裂缝透光的神秘石头。五瓣抓手一次采样成功。舱内检测系统解析出外星文明的友好留言，投出一个外星小朋友挥手的影像，揭晓石头是送给地球孩子的礼物。飞船返航，蓝色矮行星悄悄睁开卡通萌眼，目送飞船，队员并未看到。最后邀请观众打开实物石头模型。

所有台词均为同一位成年女性旁白，语气温暖、好奇；系统和外星小朋友均不说话。屏幕字、扫描框、礼物图标、投影效果、音乐与旁白后期添加。石头没有地球图案或任何文字标记。影片不提前展示具体礼物内容。

## 二、模型与调用路线核实

截至2026-11-02，已查阅[MiniMax官方V2创建任务文档](https://platform.minimax.io/docs/api-reference/video-generation-v2-create)。模型必须明确使用 `MiniMax-H3-Max`。该版本支持5—15秒整数时长、480P或768P，支持首尾帧和多模态参考；不支持原生2K。本轮统一采用480P试制，先评估造型、动作、连续性与剪辑效果；通过后另行规划2K重制。H3 Max不支持原生2K，届时需选择支持2K的模型并重新验证参考图与动作一致性，不能直接给Max传入2K参数。

本机 `mmx video generate --help` 当前仅明确列出基础 `MiniMax-H3`；不能把基础H3命令当作Max命令。`mmx-h3-video`技能也明确只处理基础H3。因此本片Max制作以官方V2接口为依据，不套用基础H3的4秒下限或2K参数。

项目已有 `视频/H3-Max方案/scripts/minimax_production.py`，其视频路径明确使用 `MiniMax-H3-Max`，但输出根目录、任务日志和素材路径绑定旧方案。这里只将它作为已有实现参考；正式执行前需检查其路径与请求结构，不能直接拿旧任务ID或旧输出目录提交新片。本轮不改动或运行该脚本，也不新建付费提交脚本。

API结构示意（不是可直接提交的完整请求；本地图片路径必须先转为真实可访问URL或合法数据URI）：

```json
{
  "model": "MiniMax-H3-Max",
  "resolution": "480P",
  "duration": 5,
  "ratio": "16:9",
  "content": [
    {"type": "text", "text": "本文件对应镜头的完整提示词"},
    {"type": "image_url", "image_url": {"url": "替换为参考图URL或数据URI"}, "role": "reference_image"}
  ]
}
```

参考图模式可固定16:9。首尾帧模式的画幅取决于输入图，需先把关键帧制作成16:9；首尾帧与普通参考图模式不可混用。形象参考图不是镜头首帧，不能直接要求角色母版背景自动变成正确舰桥。

## 四、制作顺序

1. 木星与蓝色矮行星参考文件已齐；核对五人席位、舰桥色调、下层采样舱结构和实物石头比例，制作统一横屏关键帧。
2. 先录旁白草稿并建立严格30秒时间线。按下表摆入静帧做动态分镜，检查三个天体和礼物揭晓是否看得清。不要先批量生成再强行塞进30秒。
3. 逐镜准备16:9关键帧，人物镜锁身份，采样镜锁抓手、石头和舱门位置。需要首尾控制的镜头先确定起止帧；普通松散动作可用造型参考模式。
4. 优先做高风险试片S07采样和S10睁眼，各先一个版本；通过后再制作其余镜头。四秒成片镜头也至少申请五秒生成，留剪辑余量。
5. 独立生成外星小朋友挥手素材，与舰桥扫描画面后期合成，避免模型同时处理五张脸、机械动作、投影和中文字幕。
6. 每个素材下载后检查中间帧与结尾，记录任务ID、提示词版本、输入参考顺序、实际尺寸／帧率／时长、验收结果。合格素材剪入时间线。
7. 加入检测界面、中文短介绍、引力航线和结尾引导；统一旁白、音效、音乐与色调，导出并检查恰好30秒。

## 五、逐镜描述与生成安排

每个S编号为独立生成素材，计划各生成5秒，总计50秒原始视频，不含返工与合成。S08为外星角色叠加层，不与其他视频简单顺序拼接。片尾使用石头静帧轻推即可，无需增加一次付费生成。五人镜头可生成五秒后只取一秒清晰反应画面，其余留作备选。

## 六、逐镜提示词模板

以下为运动提示词正文；提交时在每条前加统一说明，并按最终实际输入补上“参考图1、参考图2”的对应对象。每条为一个独立五秒镜头，局部时间从零重新计时；不同镜头之间的空间跳切由后期完成，不要求模型从木星连续飞到柯伊伯带。

统一说明：

> 生成5秒、16:9、480P的儿童太空冒险电影镜头。沿用本镜参考图中的主体外形、材质和比例，冷蓝太空与柔和暖光，清晰轮廓、细腻3D材质，友好神秘。相机运动克制，不在镜头内部切换场景。不要生成旁白、人物说话、配乐、中文字幕、界面字、标记或水印；全部声音与UI后期制作。严格遵守本镜物体数量与动作顺序。

### S01 木星引力加速

参考图1为用户木星，参考图2为回声号v2。0—1秒建立巨大木星与接近中的唯一飞船；1—3.5秒飞船沿木星边缘外侧平滑弧线掠过，镜头轻跟随；3.5—5秒船向画面右上方远离并稳定保持朝向。尾部引擎只适度发亮，不喷出占满画面的火焰。锁定终态：飞船远离木星，无撞击、无瞬移、无新增船。

### S02 舰桥五人

参考图1为已核准的五人舰桥关键帧。0—1秒固定人数和席位；1—3秒队员轻微抬眼、注视窗外；3—5秒保持带惊喜的表情供剪辑取用。相机极缓慢推近。锁定终态：五人仍在原席位、双手基本留在操作位置，无站起、挥手或说话。

### S03 甜甜圈小行星

参考图1为天然岩冰环。0—1秒清晰建立贯穿孔；1—3.5秒一颗很小的浮冰从孔的远端穿到近端，相机只小幅侧移；3.5—5秒浮冰离开孔口，圆环缓慢转动并保持完整。锁定终态：一个岩冰环、一个贯穿孔。无食品糖霜、无金属结构、无面孔。

### S04 喷气冰石

参考图1为喷气冰石。0—1秒保持侧下方喷口及弱白气；1—2.5秒白气增强一次；2.5—4秒冰石受到偏心推力缓慢偏转；4—5秒喷流减弱，石头继续轻微转动。锁定终态：仍为同一冰石、同一喷口，无火焰、爆炸或新增喷口。

### S05 双胞胎冰球

参考图1为两颗冰球。0—1秒大球左下、小球右上，保持间隔；1—4秒两球围绕中间的共同中心移动一小段弧线，较小球移动弧线较大；4—5秒延续平缓绕行。机位固定，背景不旋转，避免把相机绕拍误当双星运动。锁定终态：恰好两球、保持各自大小与斑纹、没有相撞或融合。

### S06 石头发光

参考图1为用户蓝色星球闭眼状态，参考图2为闭合石头，参考图3仅用于定义石头发光接缝。同一场景的造型参考，不是三个连续镜头。0—1秒建立前景唯一小石头及远处蓝色星球；1—3秒镜头缓慢推向石头，其不规则接缝由暗变成金色暖光；3—5秒保持柔和发光。锁定终态：石头仍闭合，表面无图案；星球眼睛未出现。石头不变形、不自行打开、不露礼盒。

### S07 一次抓取

优先使用已经核准的抓取前首帧与抓稳后尾帧，首尾帧均为16:9。0—1秒五瓣抓手保持开放，末端与唯一石头对齐；1—2秒内侧软衬轻触石头；2—3秒五瓣平稳合拢固定，石头不受挤压变形；3—4秒机械臂携石向原下层采样舱收回；4—5秒保持抓稳并延续缓慢收回，尚未放手。锁定终态：唯一石头在抓手内，无额外石头，抓手与小臂同轴，无腕部自转，无飞到舰桥窗外的错误采样口。初始帧就靠近目标，避免五秒同时完成远距离伸臂与复杂入舱。

### S08 外星小朋友挥手

参考图1为外星小朋友。0—1秒闭口微笑、右手已经抬起；1—3.5秒右手轻摆两次，身体只有自然微动；3.5—5秒手停在抬起位置，保持微笑。锁定薄荷绿皮肤、紫色眼睛、两根触角、服装和身材。背景保持单纯深蓝以便抠像，不生成全息、光束、礼盒或文字，不张口说话。

### S09 返航

参考图1为飞船v2，参考图2为星球闭眼状态。同一场景的造型参考。0—1秒飞船位于蓝色星球前方、采样舱外门已关闭、抓手收回；1—3秒引擎适度增亮，飞船朝右上方驶离；3—5秒继续远去、体积变小。锁定终态：飞船离开画面中心，星球仍闭眼。石头已在船内，不出现在船外。

### S10 温柔睁眼

使用同一星球的闭眼首帧与睁眼尾帧。0—1秒保持普通蓝色星球地貌；1—3秒一道地貌裂缝自然展开为一只圆润可爱的卡通大眼睛；3—4秒瞳孔缓慢移向画面右上方；4—5秒保持温柔、好奇的目送表情。星球的轮廓、冰纹、光照和位置不变。无嘴巴或牙齿，无愤怒、恐怖和追赶，不出现船内队员。

## 七、旁白、检测界面与音乐

旁白按下表分句录制或合成为独立音频，再按实际语速微调起点。不要为了卡点让人物产生口型。

| 成片区间 | 旁白 | 表演与声音安排 |
|---|---|---|
| 00—04秒 | 借着木星引力，五人小队奔向柯伊伯带。 | 开场有出发感，句尾接入发现段。 |
| 04—11秒 | 石环、喷气冰石，还有跳双人舞的冰球！ | 三个名词分别对应三个天体，留小停顿。 |
| 11—16秒 | 一颗小石头，竟透出了光！ | 前半轻疑问，发光时惊喜；剩余时间留观察。 |
| 16—20秒 | 他们小心地接住了它。 | 放轻，搭配机械轻响。 |
| 20—25秒 | 原来，这是外星小朋友送给你们的礼物！ | “你们”直接面对现场孩子，句尾可跨到返航一秒。 |
| 25—28秒 | 无旁白 | 音乐收轻，萌眼睁开时一个轻柔音色点缀。 |
| 28—30秒 | 打开它，看看吧！ | 像发出友好的邀请，不喊口号。 |

旁白以清楚自然为先。若录制后超时，先缩短停顿或使用“借木星引力，小队奔向柯伊伯带”等短句，不挤占25—28秒留白。片名可在开头或片尾以小字叠加，不增加额外片头片尾时长。

检测UI统一为舰桥屏幕视角的图形信息卡。三种天体可用同一个屏幕边框叠加在外景上，形成“屏幕放大画面”的观看方式；避免多次切人物导致时间过碎。每卡最多名称加一行短介绍，保证手机和现场屏幕均可读。天体介绍与主旁白字幕错开位置，避免文字堆叠。

音乐从轻快探索转为温暖惊喜，25秒处降低密度，28秒重新亮起。生成素材的原声音轨默认静音，统一加入旁白、引擎、扫描提示、机械轻响和石头开启音，不使用来源不明的音乐。

## 八、任务记录与异常处理

正式执行前检查账户使用兼容的按量付费API凭证，不将密钥写入提示词、文档或日志。每镜任务至少记录：镜头编号、模型、生成时长、分辨率、请求时间、提示词摘要或哈希、参考顺序、任务ID、状态、文件路径及验收结论。

按官方接口创建任务后只查询同一个task_id，成功后下载该任务结果。网络断开或本地等待超时不能证明远端任务失败，不自动重提付费请求；下载失败只重试下载。任务明确失败时保留错误和ID，再决定是否制作新版本。单次提示词不超过7000字符，参考图片、视频和音频数量及媒体尺寸在提交前按官方文档核验。

本片预计10个五秒视频生成任务，不含重做、旁白、音乐与关键帧成本。实际费用在执行前按账户当时计费核算，不在本稿虚构固定价格。木星、星球参考已到位；目前仍处于素材与分镜准备阶段，尚未提交付费视频任务。

## 九、剪辑与验收

按时间表建立30秒序列，建议交付25fps、750帧，1920×1080、H.264播放版，音频48kHz。素材帧率以下载文件实际信息为准，通过剪辑软件统一；不可仅修改帧率标签导致动作变速。本轮480P试片优先按原生尺寸检查，不以放大后的清晰度代替动作验收；如需1920×1080播放版，可另行放大导出并注明来源为480P。保留无字幕母版及有字幕播放版。

重点检查：

- 总时长30秒，包含木星加速、五人露面、三种天体、唯一神秘石头、一次采样、友好文明揭晓、返航、睁眼和打开引导。
- 三种天体各有独立、可读的动作；天体信息由检测UI说明，非队员对白。
- 石头与三张定妆照属于同一造型，无地球图案，影片中看不到实物礼物的具体内容。
- 机械臂来自正确下层舱门，五瓣与手腕方向稳定，不穿模、不瞬移；回收舱到舰桥的运输通过合理时间省略完成。
- 外星小朋友闭口微笑挥手，投影来自飞船检测系统；五人不与其进行口型对话。
- 蓝色星球仅在飞船离开后睁眼，卡通萌眼温柔目送，队员不知情；25—28秒保持旁白留白。
- 最后两秒的邀请能自然接上现场打开模型的动作，所有文字在目标播放屏幕上可读，音乐不盖旁白。
