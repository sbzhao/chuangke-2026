## 试制分辨率更新（2026-11-03）

所有H3 Max视频镜头统一480P试制。E01仍采用静帧后期，无模型分辨率参数。保持16:9、生成5秒及原有剪辑时长。先评估造型、动作和节奏，再规划高清重制。当前H3 Max不支持原生2K；后续如制作原生2K，需使用支持2K的模型并重新验证一致性，不能只把Max的resolution改成2K。
