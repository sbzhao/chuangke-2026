## 一、制作总原则

1. **新资产目录是唯一参考源。** 不用旧灰服、不用旧 A 航天工装、不用旧精确距离。
2. **正片是 H3 Max 生成 + 静帧插入 + 后期 HUD；花絮才是真实拍摄。**
3. **先试片，再整片。** 先做 S02（身份）和 S06（机械），通过后再生成其余。
4. **一条 H3 只做一个动作、一个镜头运动。** 不要同时转、推、拉、摇。
5. **屏幕不生成文字。** 所有 HUD、数据、仪表界面后期叠。
6. **先锁身份，再锁机械，再锁氛围。** 身份不对，后面全白做。

## 三、电影感六要素

### 3.1 镜头与焦段

- 全景/建立：**24–28mm**，深焦，人物在环境中。
- 中景/动作：**35–50mm**，人物与机械都清楚。
- 近景/情绪：**50–85mm**，浅景深，背景化成光斑。
- 不要广角畸变、不要鱼眼。
- 2.39:1 构图：关键信息放中央安全区，上下留空间。

### 3.2 摄影机运动

- 一条只做一个运动：缓慢推近、横向平移、后侧跟拍、轻微升降。
- 速度要慢；科幻大片靠“稳”和“尺度”，不靠手持抖动。
- 抓取、睁眼这类关键动作，摄影机尽量不动，让动作自己发生。

### 3.3 光线

- 主光：冷白 5600K 顶光，柔和。
- 辅光：青色屏幕反光，打在脸和白色航天服上。
- 点缀：暖琥珀窗框灯、舱门灯。
- 警示：品红只用于急停/失败，不铺满。
- 对比：五个灯池，中间走道略暗；不要满舱均匀亮。

### 3.4 构图

- 前景/中景/背景三层：控制台在前，人物在中，星空/主屏在后。
- 尺度线索：小飞船对木星、小人物对舰桥、小石头对机械臂。
- 引导线：舱壁加强筋、灯带、扶手，把视线引向主屏或目标。
- 不要把所有东西塞满画面；留黑、留空、留呼吸。

### 3.5 色彩

- 深靛蓝 `#0B1420`、午夜蓝 `#1B2A41`、青色 `#6FE3F2`、暖琥珀 `#E8A24A`、品红 `#E85A9A` 少量。
- 低饱和、胶片颗粒、轻微暗角、轻微 halation。
- 不要霓虹泛滥、不要彩色迪斯科灯、不要塑料感。

### 3.6 声音

- 低频引擎、结构受力、伺服、液压、金属咬合。
- 真空外景不做爆炸声；舱内可闻低频。
- 抓取前 0.5 秒静音；睁眼时只留心跳。
- 音乐是“底”，不是“满”；关键动作让音效说话。

## 四、H3 提示词公式

```text
主体 + 动作 + 镜头/焦段 + 光线 + 环境 + 连续性 + 风格 + 禁止
```

### 4.1 写作规则

- **一条一个动作**：抓取就是抓取，不要同时“转身、推进、抬头”。
- **首帧决定长相**：I2V 提示词重点写“怎么动”，不要重复描述长相。
- **连续性写死**：五瓣、单块石头、同一艘船、同一套服装。
- **禁止项写全**：无文字、无乱码、无磨损、无掉漆、无油污、无高速星线、无瞬间转向。
- **短句优先**：1–3 句主体 + 动作 + 光 + 镜头 + 风格。

### 4.2 示例：S02 舰桥

```text
太空科考船舰桥内部，五名穿白色冰川折线航天服的少年船员在各自岗位：左前驾驶员双手在操纵杆，左侧机械臂手双手在双摇杆，右侧科学官手在台面边缘，右后通讯员手按耳机，后方中央指令长手压指令台。镜头从舰桥后方缓慢推近，35mm，全景深。深蓝哑光舱壁，冷白顶灯，青色仪表光，暖琥珀窗框灯。先进、干净、精密，写实电影感。无文字，无乱码，无磨损，无掉漆，无油污，不交换座位，不戴头盔。
```

### 4.3 示例：S06 机械臂接近

```text
五瓣黄铜与深灰金属末端执行器从船体采样区伸出，缓慢接近一块灰褐色凹坑小石头；石头在最后一刻转开，抓手落空；机械臂始终与船体连接，五瓣数量不变。冷蓝轮廓光，飞船暖黄窗光，深空近黑。35mm 中景，轻微跟拍。写实科幻电影，精密机械感。无文字，无乱码，无磨损，无高速星线，不出现第二块石头。
```

## 八、后期电影感

### 8.1 剪辑

- 30–34 镜，平均 2.7–3.0 秒。
- 8 个匹配剪辑：星光→光变曲线、轨迹→公转轨道、反光→眼睛、花瓣→咬合、石头→样本舱、舱门→引擎、瞳孔→黏土眼睛。
- 抓取前后留呼吸；睁眼前留静音。
- 花絮与正片之间用黑场 + 声音转换。

### 8.2 调色

- 深蓝黑底，青色高光，暖琥珀点缀。
- 低饱和，胶片颗粒，轻微暗角，轻微 halation。
- 白色航天服不要过曝；脸要能看清。
- 伴星睁眼不要变恐怖片色调。

### 8.3 HUD

- 60 条，三层：目标标识 / 动作状态 / 遥测。
- 中文主标 + 英文小字；克制密度。
- 不遮脸、手、五瓣、舱门、眼睛。
- 所有 HUD 后期叠，H3 不生成文字。

### 8.4 声音

- 低频引擎、结构受力、伺服、液压、金属咬合。
- 抓取前 0.5 秒静音；睁眼只留心跳。
- 音乐选 A–F 中一首主曲 + 一首结尾曲；抓取和睁眼处留白。

### 8.5 花絮与署名

- 30 秒：草图 → 框架 → 石头/花瓣/电路 → 调试失败 → 成品 → 署名。
- 片尾：学校/班级居中，活动名称左上角，不显示五人姓名。

## 九、H3 Max 限制与对策

| 限制 | 对策 |
|---|---|
| 5–15 秒 | 一条一个动作；用剪辑接 |
| 768P | 后期放大 + 颗粒 + 浅景深；不要期待原生 1080P |
| 身份漂移 | 用正面/侧面/专注图；一条只带对应人物；五人同框先做关键帧 |
| 手指畸形 | 少用极端手部特写；用航天服手套、工具、操纵杆遮挡 |
| 五瓣漂移 | 每条验片数花瓣；用 `mechanics/gripper` 参考 |
| 石头变形 | 固定 `objects/sample_rock_v1.png`；只允许一块 |
| 飞船几何漂移 | 固定 `ship/echo_side` / `echo_3quarter`；环段和窗位不变 |
| 文字乱码 | 提示词写“无文字”；屏幕只留青光；HUD 后期 |
| 机械穿模 | 用首尾帧锁动作；一条只做一个动作；不要快切 |
| 瞬间转向/刹停 | 提示词写“连续、克制”；剪辑用接点省略 |
