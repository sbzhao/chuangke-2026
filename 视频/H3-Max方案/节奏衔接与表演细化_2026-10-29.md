## 二、节奏诊断

### 2.1 当前节奏的问题

- 9 段：S01–S08 各 10 秒，S09 11 秒。如果每段只用一条 H3 长镜头，平均镜头长度 = 10 秒，对科幻片来说太慢。
- 每段都是“建立 → 动作 → 反应”的三拍，连续 9 次，会形成可预测的节拍：观众到第 4 段就知道“又要切了”。
- HUD 提示很全，但如果每个动作都配一条提示，画面会变成“操作说明书”，情绪被信息压住。

### 2.2 建议的解决方式

**保留 9 段生成结构，但在每段内部拆成 2–5 个剪辑镜头。**

- 目标：全片约 **30–34 个镜头**，平均镜头长度 **2.7–3.0 秒**。
- 素材结构：**9 条 H3 主镜头 + 12–15 张静帧/插入镜头 + 4–6 个 HUD/片名图形**。
- 不是每个镜头都要 H3 生成；反应镜头、空镜、物体特写用静帧 + 缓慢推近/平移即可。
- 这样既控制成本，又能把“9 段演示”变成“一部电影”。

### 2.3 建议的镜头节奏表

| 段落 | 时间 | 镜头数 | 建议切分 | 主要素材 |
|---|---|---|---|---|
| S01 | 0–10 | 3 | 极远景飞船 → 星光眨眼 → 舰桥屏幕 | H3 + 静帧 |
| S02 | 10–20 | 3 | 舰桥全景/岗位 → 指令长与驾驶员 → 飞船转向点火 | H3 |
| S03 | 20–30 | 4 | 木星极远景 → 船体掠近 → 后侧跟拍加速 → 出射 | H3 |
| S04 | 30–40 | 3 | 蓝珠全景 → 近石与反光面 → 飞船伴飞进入 | H3 + 静帧 |
| S05 | 40–50 | 4 | 舰桥全景 → 驾驶员数据 → 科学官发现 → 第二目标 | H3 + 静帧 |
| S06 | 50–60 | 5 | 机械臂手特写 → 抓手展开 → 三次接近 → 失败反应 → 计时器 | H3 + 静帧 |
| S07 | 60–70 | 4 | 花瓣张开微距 → 合拢锁定 → 回收+星光 → 科学官/机械臂手反应 | H3 + 静帧 |
| S08 | 70–80 | 4 | 转运 → 样本入舱 → 万花筒镜面 → 空轨道 | H3 + 静帧 |

> 总计约 34 个镜头。每个镜头的建议时长见第八节“逐段镜头表”。

### 2.4 呼吸点

- **抓取前**：合拢前留 0.5 秒静音，只留金属咬合。
- **抓取后**：不要马上切走；给机械臂手 0.8 秒反应，再切科学官。
- **睁眼前**：片名淡出后留 0.5 秒安静，再让眼睛完全睁开。
- **结尾**：标签保持 2.4 秒，不要急着切花絮。
- **花絮前**：黑场 0.5 秒 + 一声现实世界的桌面声，完成冷暖转换。

### 3.1 八个关键转场

| 接点 | 建议转场 | 目的 |
|---|---|---|
| S01→S02 | 星光眨动 → 主屏光变曲线的同位置匹配剪辑；电子脉冲声延续 | 把“信号”从宇宙带进舱内 |
| S02→S03 | 主推进器点火声先行，画面切木星极远景 | 用声音连接“出发”和“抵达” |
| S03→S04 | 引力弹弓轨迹弧线 → 蓝珠公转轨道弧线；速度读数淡出、距离读数淡入 | 用同一种图形语言完成时间跳跃 |
| S04→S05 | 近石反光面的高光 → 科学官屏幕/眼睛的高光 | 用“光”把物体和人物连起来 |

| S08→S09 | 舱门关闭 → 飞船引擎点火；机械声转低频 | 从“任务完成”转到“离开” |
| S09→花絮 | 眼睛瞳孔的暖光 → 黏土眼睛的暖光/手捏黏土 | 从虚构回到制作现场，最有力的匹配剪辑 |

### 3.2 空间设定

舰桥固定坐标，所有镜头遵守，避免人物“瞬移”或视线对不上：

```text
                    前窗 / 目标方向
        ┌────────────────────────────────┐
        │            主屏                │
        │  驾驶台                科学观测台│
        │  （左前）              （右中） │
        │  机械臂控制台            通讯台  │
        │  （左中）              （右后） │
        │            指令席               │
        └────────────────────────────────┘
```

- 目标（蓝珠、近石）在前窗偏左；机械臂从画面左侧伸出。
- 飞船外景统一从左向右航行；不要在不同镜头里反转方向。
- 样本舱在舰桥前下方，通过下侧窗或侧屏可见。
- 角色不交换座位；只有指令长可以站起来走动。

### 3.3 H3 分段生成的接点原则

- 段与段之间优先用**动作匹配、形状匹配、视线匹配、声音先行**，不用叠化。
- 叠化只用于明确的时间跳跃（如 S03→S04），且不超过 0.5 秒。
- 每个接点都要检查：飞船朝向、窗光方向、人物服装、五瓣数量、石头形状是否连续。
- 不要在接点处让角色从站变坐、从左变右、从亮变暗而没有交代。

### 4.2 职业化表演：不加私人道具，不加多余动作

方向已确认：五个人不靠小道具、不做绘本式小动作；靠**职业习惯、视线、呼吸和手部克制**来区分。

**原则**

- 手放在岗位上：驾驶员手不离操纵杆，机械臂手双手在机械台，科学官手在观测台，通讯员手在通讯台，指令长手在指令台或背后。
- 不做“拍一拍”“敲三下”“看一眼私人物品”这类私人化动作。
- 情绪只通过：呼吸、下颌、喉结、眨眼、握紧/放松、肩线、身体前倾/后靠。
- 反应镜头 0.3–0.6 秒，不演，不夸张。
- 唯一保留的“手势”是指令长结尾抬手示意停下——这是指挥动作，不是个人习惯。

**五个人的职业姿态**

| 人物 | 职业姿态 | 压力下 | 放松时 |
|---|---|---|---|
| 张铭轩 · 指令长 | 站姿稳，手在指令台边缘或背后 | 下颌收紧，手指压住台面 | 肩膀下降，呼一口气 |
| 张楚珺 · 驾驶员 | 双手在操纵杆/油门，眼睛扫仪表 | 呼吸变浅，拇指摩擦杆面 | 手松开，背靠座椅 |
| 汤兴昊 · 机械臂手 | 双手在机械台，肩略前倾 | 呼气、握紧再松、盯住接触点 | 手停一拍才离开操纵杆 |
| 赵以清 · 科学官 | 身体靠近观测台，手在屏幕边缘 | 手停住，视线从屏幕移到目标 | 背离开屏幕，眼睛仍看着 |
| 王一初 · 通讯员 | 手按耳机侧，身体正对通讯台 | 手指压住耳机，头微低 | 手离开耳机，静坐 |

> 这些不是“表演”，是职业习惯。观众看到的是“受过训练的人”，不是“摆动作的孩子”。

### 4.2.1 飞船内构细节承担质感

不加人物道具后，画面的丰富度由**舰桥内构**承担：

- 控制台：分层按键、拨杆、旋钮、状态灯、精密倒角面板；不做磨损、掉漆、旧化。
- 屏幕：主屏、侧屏、机械台小屏、通讯台波形屏；界面保持运行状态——波形、曲线、扫描线、数据刷新；内容后期做，H3 不生成文字。
- 结构：座椅束缚带、脚踏、扶手、头顶管线、线缆槽、通风格栅、舱壁加强筋。
- 标识：警告色块、发光标识、编号贴片；文字后期加，不要让模型生成乱码。
- 光线：冷白顶灯 + 青色屏幕光 + 暖黄舱灯；灯池分明，不要满舱均匀亮。
- 外景：船体蒙皮、对接环、天线、散热片、采样舱门、推进器喷口。

**质感基调**：先进、干净、精密，像一艘正在执行任务的现代科考船；不是二手旧船，不做锈迹、掉漆、油污。

**用法**：这些细节主要出现在**插入镜头和空镜**里，用来换气、给尺度、避免镜头单调；不要让人物去摸、拍、指这些细节，保持职业化。

### 4.2.2 仪表界面清单（后期动效）

> H3 只拍屏幕底光、反光和边框；界面全部后期合成，保证清晰、可读、不穿帮。

| 位置 | 界面内容 | 出现段落 |
|---|---|---|
| 主屏 | 周期光变曲线；双星轨道示意；目标遥测 | S01、S05 |
| 驾驶台 | 姿态仪、速度条、轨道窗口倒计时 | S02、S03、S06 |
| 机械台 | 五瓣状态图、对位十字线、接触/夹持状态 | S06、S07 |
| 科学台 | 光谱/光变曲线、图像增强、第二目标识别 | S05 |
| 通讯台 | 信号波形、信号强度、通道状态 | S02、S07、S08 |
| 样本舱 | 密封状态、光学阵列状态 | S08 |

**规则**

- 界面保持运行：波形滚动、曲线刷新、状态灯呼吸、扫描线移动；不要静态截图。
- 颜色统一：青色/白色为主，品红只做警示。
- 字体用技术字体，数字等宽；不生成无意义乱码。
- 界面亮度低于人物脸部，不抢戏。
- 屏幕反光要打在人物脸上/服装上，增强真实感。

### 6.2 动作规则

- **手先到，屏幕后响应**；不要让屏幕先亮、手再碰。
- **抓取动作分三步**：接触 → 锁定 → 回收；不要一个动作瞬间完成。
- **反应镜头留 0.4–0.8 秒**，不要事件一发生就切走。
- **不要全员同时点头/同时看同一个方向**；真实反应有先后。
- **避免大幅挥手/夸张表情**；这是克制的科幻片，情绪靠眼神和呼吸。

## 九、其他需要精细化处理的部分

### 9.1 连续性圣经

做一份 `连续性设定.md`，锁定：

- 飞船：长度、环段数量、窗位、采样区位置、暖窗方向。
- 舰桥：岗位布局、主屏位置、前窗方向、样本舱位置。
- 服装：冰川折线五人的折线走向、胸舱、手套、徽章位置；舱内不戴头盔。
- 道具：五瓣抓手（始终五片）、近石形状/反光面、样本舱、伴体闭合/睁开。
- 颜色：冷蓝舱内、青色控制台、暖黄船灯、品红只做警示。
- 文字：所有 HUD 后期添加，H3 不生成任何文字。

### 9.2 第二颗的揭示顺序

- 先让观众在画面里看到那个暗点（不要先出标签）。
- 再让科学官动作变化（调亮、手停）。
- 再出“第二目标 · 未编目”。
- 最后出双星轨道弧线。
- 这样观众是“自己发现的”，不是“被文字告知的”。

### 9.3 道德线

- 抓取成功后，必须给汤兴昊一个“得意 → 愧疚”的 0.8 秒反应。
- 结尾看空轨道时，让他的手仍握在操纵杆上，过一拍才松开，而不是马上转回屏幕。
- 这是全片的情感重心：我们带走的是别人的伴。

### 9.4 万花筒

- 不要只拍镜面特效；加一个张楚珺的脸/手在镜面里的倒影。
- 让观众意识到：人被“一千个它”包围，但她只有一个。

### 9.5 指令长的“等等”

- 不要喊，不要挥手；只抬手、停住。
- 先近景手，再近景眼睛，再切窗外。
- 船员转头的顺序：赵以清 → 张楚珺 → 汤兴昊 → 王一初，不要同时转。

### 9.6 花絮转场

- 正片最后一个镜头是眼睛瞳孔的暖光。
- 花絮第一个镜头是手把黏土拍在桌上，或一只捏好的黏土眼睛。
- 用“瞳孔 → 黏土眼睛”的形状匹配，完成从虚构到现实的过渡。

### 9.7 H3 生成风险

- 身份漂移：每条只传对应人物参考；五人同框先做共同关键帧。
- 手指畸形：少用极端手部特写；用手套/工具/操作杆遮挡。
- 五瓣数量漂移：抓手镜头必须逐帧数花瓣。
- 石头形状漂移：固定一块参考石头，所有镜头同一轮廓。
- 文字乱码：H3 不生成文字，所有 HUD 后期加。
- 飞船几何漂移：外景统一同一参考模型，环段/窗位不变。
