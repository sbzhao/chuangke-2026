## 世界、道具与科学连续性

故事在柯伊伯带，不显示精确距离。木星引力辅助只出现在途中回忆，不与目的地混淆。无需表现六秒完成整次飞掠。引力辅助改变相对太阳的速度和方向，不以绕圈或突然弹射表现。参考：[NASA引力辅助原理](https://science.nasa.gov/learn/basics-of-space-flight/primer/)。

冰质矮行星为远景背景；近石是可收纳的小型岩块，伴体比近石大，两者被设定为该系统中长期相伴的天体。具体尺寸、质量、间距和轨道参数不在片中标定，不能宣称已完成真实轨道计算。十六小时是光变周期；十六分钟是本次相对几何条件下的操作窗口，两者不能混用。小岩块长期保留的完整历史是故事设定，不作为测年事实。四十六亿年表达太阳系原始物质的年代；结尾“只看过一样东西”属于文学表达。睁眼为唯一超现实核心设定，动作温和，没有血肉、尖牙或惊吓。

飞船约为可容纳五人的小型科考船，固定白灰旧化船壳、中央圆柱舱段、环状结构和唯一暖窗。抓手为黄铜与深灰金属、恰好五瓣、有铰链与软接触垫，始终连接机械臂。近石为不规则灰褐岩块，固定一处平滑反光切面。三角样本盒尺度大于近石，配托座、夹持件与可关闭入口；镜面增加的是倒影。伴体固定两处陨坑及一道弧形山脊，结尾才张开，无睫毛、血丝或怪兽脸。

外景星场基本稳定，不用快速星星划过表示航行。飞船惯性漂移，旋转须姿态喷口产生力矩；改变朝向不等于瞬间改变速度。采样前匹配相对速度，抓取后缓慢回收，不把一颗巨大天体拖进小盒。真空中没有传播的爆炸或引擎声，相关声响只作为舱内听感或非写实设计。飞船舱内人员固定于岗位，姿势与道具需符合失重条件，不额外声称人工重力已经实现。

## 童声与台词制作

五个角色和旁白共六个固定voice_id。不是克隆成员声音，不承诺与成员本人相似。张铭轩沉稳童声；张楚珺清晰利落童声；汤兴昊专注稍紧张童声；赵以清敏感、轻声的童声；王一初平稳报告童声；旁白为独立、自然克制的普通话童声。不用成人声强行升调扮小孩，不使用喊叫式动画配音。

先运行 `mmx speech voices --output json --non-interactive` 查询实际可用音色，选择候选并生成简短试听，听后固定ID。不能编造voice_id；如果当前列表没有合适童声，先确认可用声音设计路径，不能默认模型一定具备合适预置音色。此处声音ID暂留为待定，文档没有提交试听任务。

```bash
mmx speech synthesize --model speech-2.8-hd \
  --voice '<试听后固定的voice_id>' \
  --text-file 视频/H3制作请求/audio_text/05_01_张铭轩.txt \
  --speed 1 --emotion calm --format wav --sample-rate 32000 \
  --out 视频/H3制作请求/audio/05_01_张铭轩.wav --non-interactive
```

音色与情绪参数是生成条件，不保证自动满足年龄听感。初始正常语速，句间适度停顿。测量音频真实长度后再锁定视频时长；超长先延长镜头/把对白放到外景，不砍字、不抢读。每条参考音频2–15秒；短句可在混音轨补安静头尾，超过15秒拆条。04与14含两位说话人，先逐句TTS，再按顺序合成单条 `04_mix.wav` / `14_mix.wav`，旁白和角色绝不重叠。其余有声条目使用单条wav。最终母版以这些独立TTS音轨为准，H3声轨只作为口型审核和环境声候选，避免重复混入对白。

**声音**：旁白：“在太阳系尽头，有一道光。每隔约十六小时，它就出现一次。”

**衔接**：起点近黑；终点光点位于右上三分之一。下一条是不同年代的途中回忆，采用明确硬切，不伪装同一空间。
