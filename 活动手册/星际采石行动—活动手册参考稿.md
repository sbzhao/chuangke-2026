## 第一阶段：查询资料，初探造物

### 1. 我想了解的探险世界

我对太空探险很感兴趣。我们在故事里想完成一次“采集岩石样本”的任务：花瓣抓手接近岩石，把它送进样本容器，再让舞台背景的眼睛睁开，好像这个神秘世界被唤醒了。

我觉得探险不只是去很远的地方，也是带着问题观察、尝试和记录。航海探险、极地科考、深海调查和太空探测，都可以成为我们研究的方向。探险带来新的发现，也需要尊重环境、认真核对证据。

### 2. 我的科考工具图

**画面题目：**《花瓣采样器的任务》  
**绘制／剪贴内容：** 一支采样机械抓手、一块岩石、一个样本盒，用箭头表示“靠近—采集—保存”。  
**我的兴趣：** 花瓣看起来柔软，机械却需要准确运动。我想知道怎样把两者结合起来。  
**我的疑问：** 岩石被鱼线挂住后，怎样才能取下来？吸住以后又怎样放开？

## 第三阶段：集思广益，绘制蓝图

### 1. 我的设计思路

我们把圆柱舞台想象成一个太空采样站：上方悬挂岩石，下方是有陨石坑的行星地表。弯曲的金属“花茎”托起花瓣抓手，旁边是带圆环装饰的三角形样本容器。背景使用浅色纸面和深色线条，画着藤蔓、花和眼睛。

**我负责的重点：** 让天顶、支撑和底座连接牢固，给抓手留出空间，同时让观众看得清楚。

### 2. 整体设计图与注释

![新版整体概念设计图](images/space-rock-theater-concept-v2.png)

| 图中位置 | 设计思路 | 实现方法／待验证事项 |
|---|---|---|
| 上部圆形天顶 | 悬挂岩石，形成圆形舞台边界 | 选择轻质板材与连接方式，固定点需试验 |
| 竖向支撑 | 撑起天顶，尽量保持前方视线开阔 | 支撑数量、间距和高度由尺寸试验确定 |
| 中部花瓣抓手 | 长花瓣和曲线花茎形成植物雕塑感 | 装饰与承力结构分开考虑，开合和移动方式待试验 |
| 下方基座 | 用陨石坑表现行星地表 | 轻质材料塑形，保留安装和检修位置 |
| 三角形容器 | 让样本看得见、放得进 | 透明板或透明片制作，入口尺寸待测量 |
| 后方背景 | 抓取成功后，眼睛睁开 | 使用屏幕或投影播放动画，设备和安装方式待定 |

**尺寸记录：** 基座直径____厘米；总高____厘米；花瓣最大展开宽度____厘米；容器入口____厘米；岩石质量____克。数据由实际测量填写。

### 3. 思维导图（可照着绘制）

中心：**星际采石行动**

- 故事：发现目标 → 接近 → 采集 → 眼睛睁开 → 样本入库。
- 结构：天顶、支撑、底座、容器。
- 机械：悬挂分离、吸附、转运、释放、复位。
- 美术：花瓣、曲线花茎、陨石坑、版画背景。
- 程序：启动、动作顺序、成功信号、动画、复位。
- 合作：提出需求、画图说明、共同试验、记录修改。

### 4. 四个特色设计

| 特色设计 | 功能 | 候选材料（不是采购定稿） | 技术与实现方法 | 可能的困难及试验方向 |
|---|---|---|---|---|
| ① 圆柱舞台与陨石坑地表 | 支撑作品，交代太空环境 | 轻质板材、支撑杆、纸浆或轻质黏土 | 圆形框架连接；地表分层塑形；预留安装位置 | 天顶偏重、装饰挡住机构；先做框架试装，再加装饰 |
| ② 悬挂岩石与花瓣采样器 | 表现漂浮并完成采集转运 | 轻质岩石外壳、封装小磁铁、透明鱼线、花瓣薄片、驱动与支架待定 | 磁力吸附；脱线、移动和释放方式通过单件试验确定 | 磁力、重量与分离力不匹配；花瓣碰撞；先验证单颗岩石完整流程 |
| ③ 三角形样本容器 | 接收并展示样本 | 透明片、框架材料、圆环装饰、缓冲垫 | 设置可到达的入口和可取回样本的开口 | 入口过小、样本弹出；用实物反复试投，记录结果 |
| ④ 抓取触发的睁眼背景 | 让采集动作推动剧情，产生互动惊喜 | 背景图、眼睛动画、屏幕或投影、控制设备待定 | 程序接收抓取成功信号后播放睁眼动画 | 把“执行抓取指令”误当成功；需明确传感器判断或人工确认方式 |

### 5. 我们的微剧场：六幕故事（建议稿）

| 幕次 | 画面与动作 | 讲解／声音参考 |
|---|---|---|
| 1 发现 | 岩石悬挂，背景眼睛闭合 | “我们发现了一块神秘的太空岩石。” |
| 2 靠近 | 花瓣抓手接近目标 | “慢一点，先对准目标！” |
| 3 采集 | 抓手吸附，岩石按验证后的方式脱离悬挂点 | “采集是否成功？请确认！” |
| 4 唤醒 | 确认成功后，背景眼睛逐渐睁开 | “看！这个世界醒来了！” |
| 5 入库 | 抓手转运，岩石释放到容器 | “样本进入研究舱。” |
| 6 结束 | 展示样本，机构复位 | “新的发现，来自大家一起努力！” |

### 6. 程序逻辑与待决定事项

建议顺序：**启动 → 靠近目标 → 执行抓取 → 确认成功 → 播放睁眼动画 → 转运 → 释放 → 复位**。

尚未确定成功检测方案时，可以用人工确认进行演示，但手册应如实写“人工确认触发”，不能写成自动识别。鱼线悬挂是模型表现手段；容器中的磁悬浮不属于当前已确定功能。
