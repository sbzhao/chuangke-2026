# 活动手册制作建议

## 一、总体原则

五位同学采用**统一的手册模板，根据各自的角色和实际活动填写内容**。这样既能展示同一个项目，也能看出每个人的贡献。

手册的栏目、页面顺序、排版和互动形式保持一致，主要差异体现在每个人的研究、设计、制作、合作和反思中。共同的图表可以复用，但“我的想法、行动和收获”要由每个人自己表达。

## 二、团队分工

| 同学 | 负责角色 |
|---|---|
| A | 模型与搭建 |
| B | 机械与工程 |
| C | 美工与装饰 |
| D | 编程与应用 |
| E | 记录与表达 |

## 三、五个阶段相同，每个人记录的重点不同

| 手册部分 | 五个人共同遵守的要求 | 根据个人角色填写的内容 |
|---|---|---|
| 自我介绍 | 统一设置照片、兴趣、特长、任务栏 | 为什么适合这个角色，希望学会什么 |
| 第一阶段：查询资料 | 都要有资料、绘画或剪贴，以及自己的疑问 | 查询与自己任务相关的知识 |
| 第二阶段：组建团队 | 使用同一份团队分工表、日程表 | 我的具体任务、需要谁配合、可能遇到的困难 |
| 第三阶段：绘制蓝图 | 展示同一个整体方案和四个特色设计 | 标注我参与的部分，补充自己的设计细节 |
| 第四阶段：动手实践 | 都使用规定的四周、6行2列表格 | 记录自己做了什么、遇到什么问题、如何与同伴解决 |
| 第五阶段：成果分享 | 都包含作品照片、视频二维码、徽章和海报 | 我的成果、展示任务、收获与反思 |

## 四、五个角色分别补充什么

| 同学与角色 | 建议重点保留的材料 | 可以思考的问题 |
|---|---|---|
| A：模型与搭建 | 舞台尺寸图、搭建草图、材料清单、搭建前后照片 | 模型怎样站稳？怎样给机关和线路留位置？ |
| B：机械与工程 | 机关结构图、运动箭头、连接照片、测试记录 | 机关怎样运动？为什么卡住？怎样改得更顺畅？ |
| C：美工与装饰 | 配色卡、场景草图、材料试样、装饰前后对比 | 颜色怎样配合剧情？装饰会不会挡住运动部件？ |
| D：编程与应用 | 程序流程图、关键程序截图、声光动作顺序、调试记录 | 什么条件触发动作？动作和声音怎样配合？ |
| E：记录与表达 | 会议笔记、拍摄计划、照片说明、讲解稿修改、展示记录 | 怎样拍清楚关键过程？怎样让观众听懂作品？ |

E同学负责整理团队资料，但**每个人仍要写自己的周记录和感受**。E也要呈现自己的设计与改进，例如怎样调整拍摄角度、精简讲解稿、安排展示顺序。

## 五、用统一的小栏目体现沟通与协作

建议在每个人的周记录旁，都增加同样的“合作小窗口”，不改变原来规定的表格。

> **这周我和谁合作：**  
> **我提供了什么：**  
> **对方帮助了我什么：**  
> **我们一起作出的决定：**

例如，A同学可以写：

> 我原来搭的底座比较窄。B同学发现机关转动时会碰到墙壁。我们一起量了尺寸，把底座加宽，再请C同学调整外面的装饰。

同一件事，B同学可以从“发现机关空间不足、与A一起调整”的角度记录。这样能看出相互配合，又不会内容完全一样。以上只是写法示例，实际填写时应记录真实发生的事情。

## 六、艺术感和科技感使用同一套设计

- **同款封面：** 项目名称、团队徽章、个人姓名和角色。
- **同款页面：** 标题、主图、简短说明、“我的发现”和“合作小窗口”放在固定位置。
- **角色识别色：** 五人各用一种颜色，方便区分，整体配色保持协调。
- **同款互动页：** 例如都用翻翻页展示“表面效果与背后原理”，只是内容分别对应模型、机关、美工、程序和记录表达。

“背后原理”不一定都是机械结构。C可以展示装饰材料与制作方法，E可以展示“一张展示照片是怎样拍出来的”。

艺术感可以通过手绘、拼贴、配色和留白呈现；科技感可以通过结构图、动作箭头、程序流程图、测试记录和视频二维码呈现。互动结构应帮助读者理解作品。

## 七、填写时最重要的提醒

把“负责什么”写成**“实际完成了什么、怎样改进、怎样与别人配合”**。这会让五本形式统一的手册，各自都有真实、鲜明的内容。
